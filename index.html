How to explore the prototype
Mobile flowHome → Scan QR → Connecting → Dashboard, then the 5 bottom tabs: Home, Files, Clipboard, Tools, Settings.
Desktop flowSidebar: Overview, Files, Clipboard, Keyboard, Mouse, Screen, Ring Phone, Settings.
State switcherUse the buttons above (or Settings → Prototype inside each app) to jump between disconnected, connecting, connected and error.
Screen sharePhone: Tools → Screen Share → Start Sharing (Android permission dialog). Desktop: Screen → live view, quality, fullscreen, screenshot, stop.
